# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of this project.

| Version | Supported |
| ------- | --------- |
| Latest stable release | :white_check_mark: |
| Older releases | :x: |
| Development branches | :warning: Best effort only |

Users should upgrade to the latest stable version before reporting an issue. Security fixes may not include older versions.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

- Open a private security advisory through the repository's **Security** tab, if available. or
- Contact the maintainer through the private contact method listed in the repository.

Please include:

- A clear description of the vulnerability
- The affected version or commit
- Steps to reproduce the issue
- The potential impact
- Any proof-of-concept code, logs, or screenshots
- A suggested fix, if you have one

Please do not include real passwords, API keys, personal information, or other sensitive data in your report.

## Response Process

This is a solo project, so response times may vary. I will make an effort to:

1. Acknowledge valid reports when possible
2. Investigate and reproduce the issue
3. Release a fix or mitigation when appropriate
4. Credit the reporter, unless they prefer to remain anonymous

There is no guaranteed response or resolution time.

## Disclosure

Please allow reasonable time for investigation and a fix before publicly disclosing a vulnerability. Coordinated disclosure is preferred.

Once a fix is available, the vulnerability may be documented in the release notes or security advisories. Details that could enable exploitation may be withheld or delayed.

## Scope

This policy covers security issues in the application source code and its official release packages.

Issues in third-party software, operating systems, graphics drivers, Python itself, or unofficial forks should be reported to the relevant project. However, please report vulnerabilities caused by how this project uses a dependency.

## Security Updates

Security fixes will be published through the project's normal release channels. Users should keep the application and its Python dependencies updated.
